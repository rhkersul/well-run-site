# Mídia das mini-categorias

Clipes e capas usados no carrossel do topo do app.

- Fonte: Pexels (licença gratuita, uso comercial permitido, sem exigência
  de atribuição). Ainda assim, os autores estão creditados abaixo.
- Formato: MP4 H.264 640x360, mudo, feito para rodar em loop num card
  pequeno. Servidos pelo GitHub Pages e transmitidos sob demanda — não
  entram no APK.

novo na hora, sem precisar publicar versão nova.
