# Mídia das mini-categorias

Clipes e capas do carrossel do topo do app.

- Fonte: Pexels (licença gratuita, uso comercial permitido).
- Formato: MP4 H.264 **1280x720**, mudo, para rodar em loop num card
  vertical. Servidos pelo GitHub Pages e transmitidos sob demanda — não
  entram no APK.
- Curadoria: clipes escolhidos com olho em produção (luz, cor, composição).
